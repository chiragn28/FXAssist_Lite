# helm

First-party Helm chart for kind: ConfigMap, Secret (placeholders only), startup/readiness/liveness probes, resource requests and limits, PodDisruptionBudget, HPA for the gateway, and the watchdog CronJob with minimal RBAC (ADR-013).

Built in **Phase 4**. Note: Helm 4 is current (see docs/VERSIONS.md); use Helm 4 docs.
